## Working rules (every session)

1. **Read this file before doing anything.** Then read `CLAUDE.md` and `docs/P1-plan.md`.
2. **One phase per session.** Do not start the next phase even if time permits — leave clean handoff state instead.
3. **Small commits.** Each logical step gets its own commit. Commit messages start with `p1(phase-N): ...`.
4. **Update this file in the same commit as the code changes.** Tick checkboxes as tasks complete; update the Status block.
5. **New files in TypeScript.** Any new file created in P1 is `.ts`. If you materially rewrite an existing `.js` file, rename it to `.ts` in the same commit.
6. **App must boot at end of every commit.** `npm run dev` boots, no view crashes, `npm run typecheck` exits 0.
7. **Decisions get ADRs.** Anything non-obvious → `docs/decisions/NNNN-title.md`. Next available number is `0006`.
8. **`TODO(p0-cleanup)` items:** if you touch a file that has one of these, resolve it if it takes < 10 min; otherwise leave it and note it here.
